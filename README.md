# Weather‑App

A simple Weather App built with **Flutter** that displays current weather information. This project is a starter Flutter application with platform support for Android, iOS, Web, Windows, macOS, and Linux. :contentReference[oaicite:1]{index=1}

## 🚀 Features

- Fetch current weather data from a weather API (e.g., OpenWeatherMap)
- Search weather by city
- Clean and responsive UI
- Multi‑platform support (mobile & desktop & web) :contentReference[oaicite:2]{index=2}
